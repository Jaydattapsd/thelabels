# Build The Labels business website

## Scope
- Build a polished, responsive single-page business website using the selected frosted industrial direction.
- Preserve the supplied brand identity, wording, product categories, services, and the sole phone number `+91 97256 62466`.
- Use the uploaded card only as a branding reference, not as page artwork.

## Design and imagery
- Define the selected navy, royal blue, light blue, white, Sora, and Manrope design system.
- Generate a cohesive set of realistic product photographs for the hero and five product categories.
- Use restrained frosted panels, subtle diagonal details, modest corners, whitespace, and lightweight motion.

## Page experience
- Add a compact sticky header, desktop navigation, and mobile menu.
- Build Home, About, Products, Services, Why Choose Us, Customer Support, Quote, CTA, and Footer sections.
- Add product-aware “Enquire Now” actions that preselect the relevant quote category.
- Add call, WhatsApp, email, website, and location actions plus a floating support menu.
- Build a validated quote form with an on-page confirmation message and clear future-integration boundary.

## Quality checks
- Add route-specific SEO and social metadata with semantic headings and image alt text.
- Verify desktop and mobile layouts, navigation, product selection, support menu, contact links, and form confirmation.
- Check the final preview for overflow, overlap, visual consistency, and build errors.

## Technical details
- Implement at `/` with reusable React sections and client-side state; no backend or email delivery will be added.
- Load Sora and Manrope from the document head and keep visual values in semantic CSS tokens.
- Store generated media through the project asset flow and reference the resulting asset pointers.
