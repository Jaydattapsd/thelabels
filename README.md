--------------------------------------------------
1. OVERALL DESIGN DIRECTION
--------------------------------------------------

Take visual inspiration from the attached visiting card.

Use the same general brand identity:
- White background as the main base
- Deep/dark blue
- Royal blue
- Light blue accents
- Black for important text
- Clean geometric shapes
- Subtle blue diagonal elements inspired by the visiting card
- Professional typography
- Plenty of whitespace
- Clean borders and rounded corners

DO NOT simply recreate the visiting card.

Instead, transform its branding into a polished modern website.

The website must NOT look cluttered or like a collection of random product images.

Use a consistent visual hierarchy and spacing system throughout the website.

The overall feeling should be:
Professional + Reliable + Modern + Industrial + Clean + Trustworthy.

Avoid:
- Excessive gradients
- Too many colors
- Excessive animations
- Random floating elements
- Overcrowded sections
- Generic startup-style design
- Excessive glassmorphism
- Unnecessary decorative elements
